# Portfolio for a friend

Single-page portfolio site for a game designer, made for a friend applying to
game studios. Each project gets a section shaped to the kind of work it is -
illustrated, pixel art, or documentation only - instead of one card template,
so the text-only work holds the same weight as the visual work.

The brief that shaped it, from PRODUCT.md: the readers are hiring leads at game
studios, scanning many portfolios on their phones, so the page is mobile-first,
calm by default, and saves its motion for one moment per project that shows how
that project works. DESIGN.md carries the design system: a scroll journey from a
light, paper-white studio into a dark, cinematic canvas. A single-file
standalone build (scripts/build-standalone.mjs) ships next to the site.

Built solo, 2026. Next.js, TypeScript, Tailwind.

Status: live.
